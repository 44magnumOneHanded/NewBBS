# 放課後ボード

高校生向けのシンプルな掲示板デモです。

## ローカルで確認
Node.js 20以上をインストールし、プロジェクトフォルダで実行します。

```bash
npm start
```

ブラウザで `http://localhost:8080` を開きます。

## GitHubへ
1. GitHubで Public リポジトリを作成する
2. このフォルダ内のファイルをリポジトリに push する
3. SASトークン、発行プロファイル、接続文字列などの秘密情報は絶対にコミットしない

## Azure App Serviceへ手動デプロイ
1. Azure Portalで App Service を作成する
2. 発行元：コード、ランタイムスタック：Node.js 20 LTS以上、OS：Linux を選ぶ
3. App Service の「構成」→「全般設定」で起動コマンドが必要な場合は `npm start` を指定する
4. デプロイセンターまたは ZIP デプロイでプロジェクト一式を公開する
5. App Service の URL を開いて動作確認する

## このデモの制限
投稿はブラウザの localStorage に保存されます。同じブラウザ内では再表示できますが、
他の利用者・端末とは共有されません。全員で共有するには、Flask等のAPIとデータベースが必要です。
